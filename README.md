# OK镜验配预判系统

浏览器端角膜塑形镜 (OK镜) 验配预判与教学模拟系统。TypeScript + WebGL2 自写着色器, 数据全部存本地 localStorage, 无需服务器。

## 运行

```bash
npm install        # 安装唯一依赖 typescript
npm run build      # 编译到 dist/
npm run serve      # 启动静态服务 http://localhost:8080
```

开发: `npm run watch` 增量编译。

## 几何精度验证

```bash
node validate.ts   # 无需编译, Node >= 22 直接运行
```

对照手算矢高公式 (独立实现的公式路径), 检查顶点间隙、基弧边缘、反转弧、定位弧、边翘等关键点的泪膜厚度, 误差要求 < 2 μm。设置页内也有同样的验证报告。

## 页面

- **患者档案**: 验光度数、眼轴、复查记录, 左右眼分开管理; 内置对称/顺规大散光/逆规/斜轴/顶点偏心五类模拟角膜
- **角膜地形**: 轴向曲率、切向曲率、高度差 (相对BFS) 图, Placido 环反射按地形反推; 支持导入 N×N 高度数据 CSV
- **镜片设计**: 四/五弧反几何, 各弧宽度曲率可调; 改降度自动重算基弧 (BC = 平K - 降度 - 压缩系数); 反转弧按目标顶点间隙自动求解; 大散光提示环曲定位弧; 订片单生成与存档
- **荧光染色模拟**: 钴蓝光+黄色滤光片效果, 泪膜厚度逐点解析计算; 眨眼动态 (上睑下压+回弹)、偏位对比; 厚区荧光淬灭; 塑形预测差异地形与牛眼图偏心量
- **复查对比**: 历次实测地形叠加、相邻变化、治疗区直径与偏心量趋势, 超阈值提醒换片
- **设置**: 荧光模型参数、告警阈值、订片单模板 (镜片厂格式可配)、数据导入导出、几何验证报告

## 几何模型

- 角膜: 双锥曲面 `z = (cx·x² + cy·y²) / (1 + √(1-(1+Qx)cx²x²-(1+Qy)cy²y²))`, 支持主子午线旋转与顶点偏心
- 镜片: 分段球面, 每段 `sag = R - √(R²-r²)`, 段间连续偏移递推
- 泪膜: `T = sag_角膜 - sag_镜片 + g`, 静止位 g 由矢高平衡 `g = max(sag_镜片 - sag_角膜)` 求得
- 荧光: `I = (1-e^(-aT))·e^(-T/b)`, 薄层上升沿 + 厚区淬灭
